# GF9 2.0 card drafts

[Karama](karama.json) uses the existing Treachery card renderer, the Action hand badge and the approved [Karama 2.0 decal](../../../media/vector/decal/karama-2-0.svg), including its refined eastern hills. The body follows the supplied card photograph and deck sheet, including the bold phrase "vulnerable advantage". The header and badge inherit the existing Special card standard.

This is the writable card value accepted by the Treachery editor's Load control, with no application ID, owner or Ruleset assignment. It is a branch draft; no application record has been created or published.

The standalone [dune ridgelines](../../../media/vector/decal/dune-ridgelines.svg) contain the exact approved hill contours extracted from the eastern point. They inherit the selected colour and preserve transparent spaces. [Variant A](../artwork/variants/karama-2-0-A.svg) remains unchanged.
