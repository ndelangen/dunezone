# Preparing the differences rulebook

The [phase 2 research dossier](differences/README.md), prepared on 26 October 2026, now contains the source comparison, six-faction findings, card/deck changes, BGG and Reddit reading, and open questions. It pins the current published books and distinguishes confirmed base-game changes from incomplete expansion announcements. The plan below remains the comparison policy.

The second book will explain the differences between GF9 2.0 and the earlier GF9 rules. Keep every explanation outside the [page-for-page book](transcript.md). This file sets up the comparison; it does not claim to be a complete rules diff.

## Establish the baseline

Use the official 2019 GF9 rulebook as the proposed starting baseline. Record its exact file hash, page count and whether each comparison concerns Basic or Advanced play. Add official errata or FAQ only as separately identified sources. Decide explicitly whether expansion interactions belong in the first differences edition.

The [existing GF9 source inventory](../gf9/README.md#sources-and-precedence) and [core coverage record](../gf9/core-coverage.json) identify earlier files. The earlier [research issue, #2216](https://github.com/ndelangen/dunezone/issues/2216), holds supplied PDFs and reference links. Verify the baseline files when comparison starts. A filename or a remembered interpretation is not enough.

The current Dune Zone GF9 books combine the earlier rules with clarifications and recorded judgements. They are a second comparison target, not an exact transcript of the old official book. Keep these questions separate:

- What changed between the official printed editions?
- What would change for someone using the existing Dune Zone GF9 books?

A discrepancy with the current Dune Zone book may come from a prior interpretation rather than a new official rule. Cite the old printed rule, the later clarification and the Dune Zone judgement when that distinction matters.

## Comparison record

Use one record per change. Do not collapse unrelated faction exceptions into a general statement.

| Field | What to record |
| --- | --- |
| Change ID | A stable local identifier, assigned when a finding exists. |
| New source | PDF page, region, OCR line IDs and visually checked wording. |
| Earlier source | Edition, file fingerprint, PDF page and exact relevant wording. |
| Earlier clarification | FAQ or erratum date/page, when applicable. |
| Dune Zone baseline | Saved edition or committed authored file and relevant judgement, if compared. |
| Category | Mechanics, wording, component, terminology or presentation. |
| Effect in play | A concrete before/after situation, checked against both sources. |
| Scope | Factions, phases, variants and expansions affected. |
| Confidence | Confirmed by both sources, needs clearer scan, or interpretation still open. |
| Book location | Intended explanation section and eventual links to stable Page/Block IDs. |

## First places to investigate

These pointers come from the supplied new source. They are a reading list, not verified before/after findings.

| New source | Investigation |

| Pages 7, 11 and 23-25 | Deck contents, Little Maker, action-card text, Karama cancellation targets and Solaris effects. Inspect the card images as well as prose. |
| Pages 16-19 and 26 | Force strength, spice strength, payment/reveal timing, traitor outcomes, lasgun/shield outcomes and the Classic Spice Dialing variant. |
| Pages 20-22 | Victory timing and hierarchy, alliances, spice transfers, shared information, negotiated surrender and note-taking. |

Glare or clipping in the new scan blocks a firm wording comparison for the affected passage. Resolve the [transcription review](transcription-review.md) first. Do not use a familiar old rule to repair the new source, then report that repair as a confirmed change.

## How to present the explanations

Start with headings, text, lists and reference tables. Existing question/answer blocks can cover interaction questions. Use battle or board examples only when they explain a verified difference. A new comparison-specific block is unnecessary until an actual explanation fails to fit those tools.

Keep the official wording available beside the explanation through stable links to the eventual as-is edition. Preserve the distinction between an official change, a correction to Dune Zone's earlier interpretation and an unresolved question. Review the complete comparison for missing faction exceptions before publishing it.
