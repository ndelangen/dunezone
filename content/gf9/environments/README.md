# Environment bindings

Both manifests start unbound. Populate origins, GF9 scope and typed destinations from actual normal authenticated readbacks. IDs can match across a snapshot and production; verify the environment separately. No owner override, account profile, credential or session token belongs here.

`inspect` prints measured baseline hashes. Local preparation records synchronization in `local-sync.json`; collect updates it after reviewed file replacement. Read the complete workflow in [authoring/README.md](../authoring/README.md).
