# Content evidence

Record source versions/hashes, clause-to-Page/Block or faction/card coverage, judgement links and actual review findings here. These files support the authored content; they do not independently generate it. Every file enters the authoring hash. No coverage or review pass is supplied by this scaffold.

Each book or component author owns its evidence subdirectory. Merge shared identities, typed bindings, links and artwork deliberately after checking their actual saved targets. Keep binary proof in durable external artifacts and record its identity/hash/link here.
