## Reconstruction and limits

Most repairs reuse the existing vector curves. The Diplomat figures and detailed Prana-bundu anatomy use new image-assisted reconstructions, converted to cubic contours. Their banner furniture and segmented field were then replaced with repeated native geometry. These are interpretations of damaged artwork, not recovered source drawings.

Palace alt and its legacy multicolor file depict the same black-only variant. Palace adds small windows and edge details to the same building. Their existing paths remain because saved documents may refer to any of them. The circular apertures and side slots now use consistent geometry.

The original source snapshot, earlier proposals and hash-bound user feedback remain in the local review archive. The dashboard can compare a revision with the original or the previously reviewed proposal. Later feedback does not retroactively approve a changed version.
